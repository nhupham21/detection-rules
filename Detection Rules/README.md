# Detection Rules

Sigma rules written alongside the vulnerability and incident analyses on [netsec101.com](https://netsec101.com). Each rule is mapped to MITRE ATT&CK and grouped by domain. Rules are starting points: test them against your own logs and tune before alerting on them.

Convert them to your SIEM with [sigma-cli](https://github.com/SigmaHQ/sigma-cli), for example `sigma convert -t splunk -p splunk_windows <rule>.yml`.
